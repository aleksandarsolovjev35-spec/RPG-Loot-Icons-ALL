# Демо: точечная чёткость для `icons-256-v2`

`comparison.png` показывает шесть иконок из `icons-256-v2` в трёх колонках:

1. исходный WebP 256×256;
2. версия `*-sharp.png` после аккуратной дорисовки существующих контуров;
3. усиленная в 6 раз карта изменений.

## Что именно сделано

Это не генеративная перерисовка и не замена рисунка. `tools/redraw_v2_demo.py`
работает только с локальными пиксельными деталями:

* мягкий `masked unsharp` усиливает уже существующие грани и фактуру;
* порог отсекает шум в плоских местах;
* жёсткое ограничение не даёт появиться светлым ореолам;
* чёрная подложка фиксируется по исходнику;
* размер, силуэт, композиция и цветокоррекция не меняются.

Сила специально умеренная: `icons-256-v2` уже прошёл `punch`, поэтому повторная
обработка не должна делать контуры «игольчатыми». Среднее изменение для шести
примеров — 0.38–0.61 уровня из 255; карта справа показывает, что правки сидят
на контурах и мелкой фактуре, а не рисуют новый объект.

Повторить демо:

```bash
.venv/bin/python tools/redraw_v2_demo.py
```

Выбрать другие иконки можно без изменения кода — передать несколько `--icon`:

```bash
.venv/bin/python tools/redraw_v2_demo.py \
  --icon "RPG Loot Icons 01/part1/icon_001.webp" \
  --icon "RPG Loot Icons 17/part2/icon_023.webp"
```

Исходный набор `icons-256-v2/` не изменяется. Получившиеся отдельные PNG можно
использовать как пробные варианты перед выбором силы обработки для остальных
иконок.
