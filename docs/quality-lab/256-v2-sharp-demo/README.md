# Демо: улучшенная чёткость для `icons-256-v2`

`comparison.png` показывает шесть иконок из `icons-256-v2` в трёх колонках:

1. исходный WebP 256×256;
2. улучшенная версия;
3. усиленная в 6 раз карта изменений.

## Что стало лучше

Первая проба усиливала уже декодированный WebP. В этой версии обработка начинается
с полного цветного кропа исходного JPG-листа, поэтому не усиливаются блоки WebP:

```text
полноцветный исходник
    -> guided denoise + anti-ringing Lanczos 256
    -> тот же стиль v2: quiet + flat + vign + fit + punch
    -> восстановление среднечастотных граней и фактуры
    -> ограниченный edge-safe sharpen
```

Это не генеративная перерисовка: геометрия, силуэт, расположение деталей и
композиция сохраняются. Обработка усиливает только уже присутствующие границы,
грани, складки и фактуру. Чёрный фон защищён от новых ореолов.

Среднее изменение относительно `icons-256-v2` для выбранных примеров — примерно
`2.9–4.2` уровня из `255`: это заметнее первой осторожной пробы, но всё ещё
остаётся локальным улучшением рисунка, а не сменой арт-дирекшена.

Повторить демо:

```bash
.venv/bin/python tools/redraw_v2_demo.py
```

Выбрать другие иконки можно без изменения кода — передать несколько `--icon`:

```bash
.venv/bin/python tools/redraw_v2_demo.py \
  --icon "RPG Loot Icons 01/part1/icon_001.webp" \
  --icon "RPG Loot Icons 17/part2/icon_023.webp"
```

Исходный набор `icons-256-v2/` не изменяется. Отдельные обработанные PNG и
параметры находятся в этой папке.
